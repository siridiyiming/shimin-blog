# 一码当先小柿民博客配置指南

## 首次进入

按 [README](../README.md) 启动本机数据库、后端和前端。首次使用时，在项目目录运行：

```powershell
.\.venv\Scripts\python -m backend.manage admin --username admin
```

按终端提示设置至少 12 位密码，输入时不会显示。然后自行在浏览器地址栏输入 `http://127.0.0.1:5173/admin` 并登录；可在自己的浏览器中保存书签。公开页面没有后台链接，但知道地址的人仍能看到登录页，实际管理权限由账号密码和后端身份验证控制。正式部署后地址对应 `https://blog.example.com/admin`，须先完成服务器与 HTTPS 配置。

## 先设置站点资料

在后台“站点设置”填写网站名称、首页短介绍、个人简介和头像。网站名称已设为“一码当先小柿民博客”，会显示在页头、页脚和浏览器标题；首页短介绍显示在首页顶部，个人简介和头像显示在首页介绍卡片。上传头像会自动生成 WebP 地址；也可以填写本站已有图片地址。资料尚未换成真实内容时保留“个人资料仍是占位内容”的勾选，完成后取消勾选并保存。

“首页开场”可填写主标题（例如“记录灵感，分享值得发现的事。”）、眉题、短介绍和开场小字；除网站名称外都可留空。勾选“手机端先展示作者介绍”时，访客先看到个人介绍，再看到轮播；取消勾选则轮播在前。电脑端保持轮播与开场区域在上、作者介绍在旁的布局。

“首页轮播图”最多添加 6 张。为每张图上传图片，按需填写标题，然后选择“直接跳转”“放大后可跳转”或“仅放大观看”；前两种需要填写 HTTP/HTTPS 跳转地址。轮播配置保存后首页才会显示该图片；不添加轮播图时首页自动隐藏此区域。已使用的轮播图片受图片库删除保护。

“联系外链”可添加最多 6 个名称与 HTTP/HTTPS 地址，显示在首页介绍卡片。比如作品主页或公开社交账号；不需要的链接留空列表即可。

## 分类标签与图片

如需按分类和标签筛选，先在“分类标签”添加相应名称，再在内容中选用。分类和标签可留空；填写后必须选用已建立的名称。重命名会同步更新关联内容，正在被使用的分类或标签不能直接删除。

“图片库”可上传 JPEG、PNG 或 WebP，单张不超过 5 MB；服务器会校验并优化成 WebP。图片可以作为头像、封面、工具图标、正文配图或游戏截图。图片库显示可复制的地址；仍被内容或站点资料引用的图片不能删除。

## 内容管理与首页

在“内容管理”点击“新建内容”，选择四种类型之一，填写标题，并按需填写分类、摘要、标签及相应字段。发布游戏和工具还须填写有效的 HTTP/HTTPS 外部访问地址；其他介绍、图片、截图、设备和操作说明均可选填：

| 类型 | 主要填写内容 | 公开展示位置 |
|---|---|---|
| 游戏 | 必填游戏地址；可选封面、介绍、设备支持、操作说明、截图及 HTTPS MP4 宣传视频直链 | 游戏列表与游戏详情，视频在站内播放 |
| 长文章 | 摘要、可选封面、富文本正文；正文标题自动组成目录 | 知识列表与文章详情 |
| 知识卡片 | 简短正文、可选配图和相关链接 | 知识列表，可展开全文和评论 |
| 工具 | 工具名称、推荐理由、图标和访问地址 | 工具列表，外链在新标签打开 |

“保存草稿”只在后台可见；“保存并预览”显示站长私有预览；“发布内容”才进入公开列表、搜索和详情。“下架”会从这些公开入口移除，后台仍保留记录。勾选“设为首页精选”后，已发布内容会进入首页对应栏目；“精选顺序”数值越小越靠前。首页近期留言从真实留言板读取，无需单独填写。

未选出精选内容的游戏、知识或工具栏目会在首页整块隐藏，不影响该栏目的列表页。“公开显示发布时间”对每条内容单独设置，默认勾选；关闭后仅隐藏公开页面上的日期，数据库仍记录发布时间并用它排序。MP4 链接须直达 HTTPS 的 `.mp4` 文件，建议素材约 30 秒；视频文件由链接所在服务提供，不会上传到博客的图片库。

当前首批内容标注为“占位示例”。可逐篇编辑成真实内容，或下架暂时不展示的示例；游戏示例中的说明与链接也应替换为实际作品信息。

## 评论留言

访客可在内容页或留言板免注册提交，成功后立即公开。“评论留言”区域可查看、以站长身份回复、单条删除或批量删除。删除有回复的主评论时，原文被清除，其下其他人的回复保留；已删除回复的引用不会继续暴露原文。读者点赞按匿名浏览器标识去重，站长无需手动维护计数。

## 公开页面如何读取配置

首页顶部读取短介绍，介绍卡片读取站点资料，三组精选卡片读取已发布且设为精选的内容。游戏、知识、工具页面自动读取各自已发布内容；知识同时包含长文章和卡片。搜索只查已发布内容，不查草稿、下架内容或评论。留言板和首页近期留言读取读者实际提交的数据。

更新已部署的旧站时，先备份 MySQL 和图片目录，再部署新版后端，在项目根目录用已配置的虚拟环境执行 `python -m backend.manage init-db`，为已有 `contents` 表补上视频地址与发布时间显示字段；该命令可重复执行且不删除已有内容。之后重启后端、上传新版 `dist`，验证首页、内容页和后台。正式服务器上的 Python 命令应使用该站实际虚拟环境的 `bin/python`；此操作只针对你为博客创建的独立数据库。
